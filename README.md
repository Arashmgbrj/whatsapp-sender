# WhatsApp Bulk Messenger - Windows Application

## 📌 پروژه چیست؟
یک اپلیکیشن ویندوزی نوشته شده با پایتون برای ارسال انبوه پیام‌های واتساپ با استفاده از سلنیوم. این برنامه امکان ارسال پیام به مخاطبین متعدد را به صورت خودکار فراهم می‌کند.

## ✨ ویژگی‌های اصلی
- ✅ ارسال پیام به چندین شماره به صورت خودکار
- ✅ پشتیبانی از پیام‌های متنی و فایل‌ها
- ✅ سیستم تأخیر قابل تنظیم بین ارسال‌ها
- ✅ لاگ کامل از عملیات‌های انجام شده
- ✅ رابط کاربری ساده و کاربرپسند
- ✅ ذخیره تنظیمات برای استفاده مجدد

## 📦 پیش‌نیازها

### 1. نصب پایتون
- دانلود Python 3.8 یا بالاتر از [python.org](https://python.org)
- هنگام نصب، گزینه **"Add Python to PATH"** را انتخاب کنید

### 2. نصب درایور مرورگر
- **ChromeDriver** مطابق با نسخه کروم شما
- دانلود از: [chromedriver.chromium.org](https://chromedriver.chromium.org/)

## 🚀 راه‌اندازی پروژه

### 1. کلون کردن ریپازیتوری
```bash
git clone https://github.com/yourusername/whatsapp-bulk-messenger.git
cd whatsapp-bulk-messenger
```

### 2. ایجاد محیط مجازی (اختیاری اما توصیه می‌شود)
```bash
python -m venv venv
venv\Scripts\activate  # در ویندوز
```

### 3. نصب requirements
```bash
pip install -r requirements.txt
```

### محتویات فایل `requirements.txt`:
```
selenium==4.15.0
pyqt5==5.15.9
pyqt5-tools==5.15.9.3.3
pandas==2.1.3
openpyxl==3.1.2
python-dotenv==1.0.0
```

### 4. ساخت فایل `.env` (اختیاری)
```env
CHROME_DRIVER_PATH=C:\path\to\chromedriver.exe
DEFAULT_DELAY=5
```

## 🖥️ نحوه اجرا

### روش ۱: اجرای مستقیم
```bash
python main.py
```

### روش ۲: ساخت فایل اجرایی (exe)
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=icon.ico main.py
```
فایل اجرایی در پوشه `dist` ایجاد می‌شود.


## 🎮 راهنمای استفاده

### ۱. آماده‌سازی مخاطبین
1. فایل Excel یا CSV حاوی شماره‌ها آماده کنید
2. فرمت شماره‌ها: `+989123456789` (با کد کشور)

### ۲. تنظیمات اولیه
1. برنامه را اجرا کنید
2. مسیر chromedriver.exe را مشخص کنید
3. فایل مخاطبین را انتخاب کنید
4. پیام‌ها را وارد کنید

### ۳. شروع ارسال
1. روی دکمه "شروع ارسال" کلیک کنید
2. QR Code واتساپ وب را اسکن کنید
3. برنامه به صورت خودکار پیام‌ها را ارسال می‌کند

## ⚠️ نکات مهم امنیتی

### ۱. رعایت قوانین واتساپ
- از این برنامه **فقط برای اهداف قانونی** استفاده کنید
- از ارسال اسپم خودداری کنید
- حریم خصوصی دیگران را رعایت کنید

### ۲. محدودیت‌های واتساپ
- واتساپ ممکن است در صورت ارسال انبوه، حساب شما را مسدود کند
- توصیه می‌شود بین ارسال‌ها تأخیر مناسب (۱۵-۳۰ ثانیه) قرار دهید
- از شماره‌های غیرمعمول (شماره جدید) استفاده نکنید

### ۳. نکات فنی
- برنامه را روی سیستم عامل اصلی خود اجرا کنید
- از VPN استفاده نکنید
- اطمینان حاصل کنید اینترنت پایدار دارید

## 🔧 عیب‌یابی

### مشکل ۱: خطای ChromeDriver
```
Message: 'chromedriver' executable needs to be in PATH
```
**راه حل:** مسیر chromedriver.exe را درست وارد کنید

### مشکل ۲: QR Code اسکن نمی‌شود
**راه حل:**
1. مطمئن شوید واتساپ روی موبایل فعال است
2. صفحه واتساپ وب را Refresh کنید
3. از اتصال اینترنت مطمئن شوید

### مشکل ۳: پیام‌ها ارسال نمی‌شوند
**راه حل:**
1. شماره‌ها را با فرمت بین‌المللی وارد کنید
2. تأخیر بین ارسال‌ها را افزایش دهید
3. برنامه را Restart کنید
